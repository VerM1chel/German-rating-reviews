# German-rating-reviews

## Как запустить

1. Установить зависимости: `pip install -r requirements.txt`
2. Скачать датасет с Kaggle и положить в корень проекта.
3. Обучить baseline: `cd core && python ml_train.py`
4. Обучить DistilBERT: `python -m distilbert.train`
5. Эксперименты: `experiments/*.ipynb`

## Данные

- **Источник:** [Patient Reviews of Doctor's (Kaggle)](https://www.kaggle.com/datasets/thedevastator/german-2021-patient-reviews-and-ratings-of-docto)
- **Лицензия:** CC BY-SA 4.0
- **Объём:** 439 280 отзывов
- **Пропуски в `rating`:** 9 544 (2%) — удалены
- **Дисбаланс классов:** 81% — оценка 1, остальные 19% — оценки 2–6
- **Средняя оценка:** 1.56 (Std = 1.34)
- **Разбиение:** 80/20, `random_state=42`, без стратификации (проверено: разница долей классов < 0.001)

## Эксперименты

### Baseline
LogisticRegression, max_iter=1000, class_weight='balanced'. F1 macro = 0.3786.

### LogisticRegression (Grid Search)
C, max_features, ngram_range. Лучшие: C=0.66, max_features=10000, ngram_range=(1,2). F1 macro = 0.3782. Не улучшил baseline.

### XGBoost (200 trees)
n_estimators=200, max_depth=6. Без sample_weight. Хуже LR.

### XGBoost (500 trees)
n_estimators=500, max_depth=4. С sample_weight. Лучше, но всё ещё хуже LR.

### XGBoost (Grid Search)
n_estimators, max_depth, max_features. Лучшие: n_estimators=200, max_depth=4, max_features=20000. F1 macro = 0.3490. Хуже LR.

### LR + ngram(1,2) + sublinear_tf
F1 macro = 0.3829 против 0.3786 у baseline. Прирост +0.0043 — в пределах шума. 
Биграммы и sublinear_tf не дают значимого улучшения: TF-IDF уже 
на пределе для линейной модели.

### SVM с линейным ядром (LinearSVC) на полном датасете
F1 macro = 0.3855 против 0.379 у LR. Прирост +0.007 — в пределах шума. 
Другой алгоритм классификации не даёт значимого улучшения: 
проблема не в выборе линейной модели.

### SVM (RBF-ядро) на подвыборке 20k
F1 macro = 0.332 против 0.379 у LR на полном датасете. Гипотеза 
о нелинейности не подтверждается: RBF-ядро на разреженных TF-IDF-признаках 
скатывается к доминирующему классу (класс 1: F1 = 0.94, класс 3: F1 = 0.02).

### LSTM: увеличение данных и модели не помогает
- LSTM v1 (80k train, 14M параметров): F1 macro = 0.3872
- LSTM v2 (160k train, 28M параметров): F1 macro = 0.3867

Вдвое больше данных и параметров — результат не изменился (0.3872 против 0.3867, 
разница в пределах шума). Это подтверждает: LSTM упирается не в объём данных, 
а в архитектуру. Последовательное чтение не даёт преимущества над TF-IDF + LR 
на коротких текстах с дисбалансом и близкими классами.

### DistilBERT (distilbert-base-german-cased, 80k, 2 эпохи)
F1 macro = 0.4405 против 0.379 у LR и 0.387 у LSTM. Прирост +0.054 — значимый.

Per-class F1 показывает: DistilBERT лучше различает выраженные оценки 
(класс 1: 0.963 vs 0.864; класс 5: 0.452 vs 0.335; класс 6: 0.504 vs 0.465), 
но на градациях 2–4 прирост минимален (0.21–0.27 против 0.19–0.22 у LR). 
Трансформер вытягивает классы с явным текстуальным сигналом, но не решает 
проблему текстуальной близости соседних оценок.

### Что проверено и не требует изменений
- Стратификация при разбиении: проверена, разница долей классов между train 
  и test < 0.001. На датасете 439k строк не влияет на метрику.

### Что можно улучшить в эксперименте
- Обучить MLP с class_weight, чтобы сравнение с LogisticRegression было честным.
- Попробовать объединение редких классов (3 класса: {1}, {2,3,4}, {5,6}) — 
  проверить, где именно ломается модель.

## Выводы

### LogisticRegression — лучший выбор по соотношению качество/время
LogisticRegression даёт F1 macro = 0.379 при обучении за 41 секунду. 
MLPClassifier показывает почти такой же результат (0.374), но обучается 4 часа. 
При ограниченном времени LogisticRegression — очевидный выбор.

### Бинарная постановка (1 vs не-1)
F1 macro = 0.837 против 0.379 в 6-классовой постановке.
Train time: 1.5s против 41s.

Вывод: линейная модель уверенно отделяет негатив от не-негатива, 
но не различает градации оценок (2–6). Проблема 6-классовой задачи — 
не в модели и не в признаках, а в избыточной детализации.
Для точной оценки 1–6 требуется модель с контекстом (DistilBERT).

### Качество зависит от размера и близости классов
Модель хорошо отделяет оценку 1 от остальных (F1 = 0.86), но внутри 
«не-1» работает на уровне случайного угадывания (F1 = 0.19–0.46). 
Это не дефект модели, а свойство данных: сильный дисбаланс (81% — оценка 1) 
и текстуальная близость соседних оценок (1-2, 5-6).

### XGBoost проигрывает даже с балансировкой классов
XGBoost с компенсацией дисбаланса (sample_weight) даёт F1 macro = 0.351 — 
всё равно ниже, чем у LogisticRegression (0.379). Значит, дело не только 
в дисбалансе. Вероятная причина — градиентный бустинг хуже работает 
с разреженными TF-IDF-признаками при 6 классах. Это гипотеза, 
требующая отдельной проверки.

### Grid Search не улучшил baseline
Поиск гиперпараметров для LogisticRegression дал F1 macro = 0.378 
против 0.379 у baseline. Причина: поиск шёл одновременно по гиперпараметрам 
и по пространству признаков, поэтому сравнение с baseline не совсем корректное. 
Чтобы честно оценить вклад гиперпараметров, нужно фиксировать признаки.

### Влияние предобработки
Первая версия предобработки удаляла отрицания (nicht, kein) как стоп-слова 
NLTK и схлопывала любые повторы букв (dass → das, bitte → bite). Это 
потенциально могло искажать сигнал для классов 2–6.

После исправления (отрицания сохранены, повторы схлопываются только от 3+ раз): 
F1 macro = 0.3798 против 0.3786. Прирост +0.001 — в пределах шума.

Вывод: предобработка не была узким местом. Даже с корректной обработкой 
LR упирается в тот же потолок ~0.38. Однако исправление важно 
для воспроизводимости и корректности пайплайна.

### DistilBERT — значимый прирост, но не решение
DistilBERT даёт F1 macro = 0.441 против 0.379 у LR. Прирост +0.054 — 
первый значимый результат за все эксперименты. Однако per-class F1 
показывает, что улучшение сосредоточено на классах с явным сигналом (1, 5, 6); 
градации 2–4 остаются сложными для любой модели. Потолок задачи — 
не в модели, а в данных: субъективность оценок и текстуальная близость 
отзывов с оценками 2, 3, 4.

### Классический ML исчерпан
Шесть моделей (LR, XGBoost, MLP, SVM линейный, SVM RBF, бинарный LR) дают 
F1 macro в диапазоне 0.33–0.39 на 6-классовой задаче.

Гиперпараметры: перебирались для LR и XGBoost (Grid Search). Для MLP и SVM — 
нет, потому что baseline уже показывал отсутствие значимого прироста, а ресурсы 
CPU ограничены. Разброс результатов между моделями (0.33–0.39) слишком мал, 
чтобы тюнинг одной из них кардинально изменил картину.

Признаки: ngram(1,2) и sublinear_tf на LR. Прирост +0.004 — в пределах шума.
Предобработка: сохранение отрицаний на LR. Прирост +0.001 — в пределах шума.

Ни один из факторов не даёт значимого прироста. Причина — структура данных: 
сильный дисбаланс (81% — оценка 1) и текстуальная близость оценок 2–6. 
Для 6-классовой задачи требуется модель с контекстом (DistilBERT), 
которая даёт F1 macro = 0.441 — значимый, но не радикальный прирост.
